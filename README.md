# Распознавание конфликтов на видео

Описание проекта

Проект выполнен командой направления «Прикладной ИИ и компьютерное зрение».

Цель проекта — разработать прототип системы автоматического распознавания конфликтных ситуаций, в частности драк, на видеозаписях с использованием методов компьютерного зрения.

Ожидаемый продуктовый результат — приложение, которое позволяет пользователю выбрать видеофайл, выполнить его автоматический анализ и получить результат о наличии или отсутствии драки. Такой прототип может использоваться как основа для систем видеонаблюдения, где требуется автоматизировать обнаружение опасных и конфликтных ситуаций.

## Для оценки и настройки модели был собран собственный датасет из 2000 видеозаписей.

fight
1000
Видео, на которых присутствует драка или конфликтная ситуация

non-fight
1000
Видео без драки, обычные действия людей

Источниками данных стали открытые датасеты, включая Hockey Fights и часть RWF-2000, а также собственные видеозаписи.

Видео не имели разметки bounding boxes, то есть для них не задавались координаты
объектов на кадрах. Вместо этого использовалась бинарная разметка на уровне всего
видео: драка или не драка. Такой формат позволил использовать датасет для оценки
уверенности модели и подбора оптимального порога принятия решения.

## Модель

В проекте использовались предобученные модели YOLOv8 из открытого репозитория для
распознавания драк и насилия на видео.

Для сравнения были взяты две модели:
yolo_small_weights.pt 

Средняя уверенность: 0.73 

Время обработки тестового видео: 376.4 сек

Yolo_nano_weights.pt

Средняя уверенность: 0.68 

Время обработки тестового видео: 235.4 с

Модель YOLOv8 nano работала быстрее, но показывала меньшую среднюю уверенность.
Для задачи обнаружения конфликтов более важна точность, поэтому в качестве основной
модели была выбрана YOLOv8 small.
